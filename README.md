# Проект «Код признания: Анна Янковская»

Website project for the oblast digital competition "Digital Portrait of a Master: Chronicle of Women's Success"

## О проекте

Сайт посвящён педагогу Янковской Анне Владимировне — заведующему учебно-методическим кабинетом, педагогу дополнительного образования ГУО «Лидский районный центр творчества детей и молодёжи».

## Технологии

- React 18 + TypeScript
- Vite
- CSS Modules
- Адаптивная вёрстка

## Запуск

```bash
cd teacher-portrait-site
npm install
npm run dev
```

## Структура данных

- `src/data/teacherData.ts` — биографические данные педагога
- `src/data/achievements.ts` — события таймлайна (награды педагога, достижения учащихся)
- `src/data/library.ts` — категории методической библиотеки

## Навигация по разделам

- Главная (Hero)
- Обо мне / Биография
- Путь педагога (Таймлайн)
- Достижения учащихся (Галерея)
- Инфографика
- Методическая библиотека
- Награды
